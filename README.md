# 💵 Personal Budget — Monthly Budgeting & Expense Allocation App

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A financial planning application designed to implement the 50/30/20 budgeting rule, track variable expenses, and avoid end-of-month financial shortfalls.

---

## 🌟 Key Features

- **Category Budget Allocations**: Set monthly limits on groceries, dining, utilities, and entertainment.
- **Over-Budget Alerts**: Visual warnings when approaching or exceeding category allocations.
- **Export & Backup**: Download financial summaries in CSV and JSON formats.

---

## 🛠️ Technology Stack

- **Technology**: Next.js, React, Tailwind CSS

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/personalbudget.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
